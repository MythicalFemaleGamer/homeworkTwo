# Singapore Travel Deals

A responsive travel-deals website for exploring Singapore travel packages and current deals. The project uses HTML, SCSS, and JavaScript modules to create a simple single-page navigation experience.

## Web4
https://in-info-web4.luddy.indianapolis.iu.edu/~jat5/homeworkTwo/

## Features

- Responsive navigation bar
- Home, About, Packages, and Current Deals pages
- Dynamically rendered page content
- Singapore-themed hero images and travel package cards
- Hover effects and transitions
- Reusable SCSS variables for colors and fonts

## Technologies

- HTML5
- SCSS/CSS
- JavaScript ES Modules
- Git/GitHub

## Dependencies

This project has no runtime dependencies.

To compile SCSS, install Sass if needed:

```bash
npm install --save-dev sass
```
